🚀 Quick Start Installation & Usage

Run locally on your Mac, Windows, or Linux machine

Terminal Commands Python 3.9+

# 1. Clone repository & set up environment

git clone https://github.com/FaezehMillerAI/FarazanPDFConverter.git
cd FarazanPDFConverter
python3 -m venv venv && source venv/bin/activate
pip install -e .

# 2. Launch the Interactive Web GUI

python scripts/pdf2word.py serve --port 8000

# 3. Or convert directly from Command Line (CLI)

python scripts/pdf2word.py convert "paper.pdf" -o "paper.docx" --mode academic
